# F3 Vintage Shop - Week 2 Code

This is the Week 2 progress version of the Assignment 3 website.

## What changed from Week 1

- Added six product cards instead of only a simple product structure.
- Added placeholder product images through the `assets` folder.
- Improved the product results page with `View details` and `Add to cart` buttons.
- Connected the Add to Cart buttons to JavaScript cart state.
- Added cart item rendering, cart count updates, subtotal updates, and item removal.
- Improved the checkout page structure.
- Added basic checkout validation before the confirmation screen appears.
- Continued improving responsive CSS for the required mobile and desktop testing sizes.

## File Map

- `index.html`: Main page sections for the shopping flow.
- `css/styles.css`: Mobile-first styling and responsive layout rules.
- `js/app.js`: Product data, page navigation, cart logic, search filtering, and checkout validation.
- `assets/`: Temporary placeholder images for product cards.
