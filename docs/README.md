# F3 Vintage Shop

F3 Vintage Shop is a vanilla HTML, CSS, and JavaScript implementation of the Figma shopping flow from Assignment 2.

## How to Run

Open this folder in a terminal and run:

```powershell
node server.js
```

Then open:

```text
http://localhost:8000/
```

## Assignment Checklist

- Built with vanilla HTML, CSS, and JavaScript only.
- Includes a complete purchase flow: Home, Search Results, Product Details, Cart, Checkout, and Confirmation.
- Supports two or more products with JavaScript product data.
- Cart count, subtotal, checkout total, and order summary are updated with JavaScript.
- Checkout has simple validation before the confirmation page appears.
- Layout is designed for the required testing sizes: 390 x 844 and 1368 x 912.

## File Map

- `index.html`: Main semantic page structure for all website screens.
- `css/styles.css`: Visual design, layout, and responsive rules for mobile and desktop.
- `js/app.js`: Product data, screen navigation, cart logic, search filtering, and checkout validation.
- `server.js`: Small local development server for viewing the project at `localhost:8000`.
