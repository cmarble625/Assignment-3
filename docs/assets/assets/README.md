# Product Image Files

Temporary SVG placeholders are included so the website does not show broken images.

When you have the real shirt photos as separate files, save them here and update the `image` paths in `js/app.js`.

- `california-vintage-tee.png`
- `y2k-print-tee.png`
- `vintage-nike-swoosh-tee.png`
- `90s-graphic-tee.png`
- `retro-streetwear-tee.png`
