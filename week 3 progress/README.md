# F3 Vintage Shop - Week 3 Final Code

This is the Week 3 final progress version of the Assignment 3 website.

## Project Summary

F3 Vintage Shop is a responsive vintage clothing shopping website built with vanilla HTML, CSS, and JavaScript. The website is based on the Assignment 2 Figma prototype and supports the main shopping journey from browsing products to checkout confirmation.

## Completed Features

- Home page with category buttons and a vintage clothing hero section.
- Search and Results page with six product cards.
- Product detail page with selected item information and size selection.
- Add to Cart buttons on product cards and the product detail page.
- Cart page with selected products, item removal, cart count, and subtotal.
- Checkout page with delivery and payment form fields.
- Basic checkout validation before confirmation.
- Confirmation page with order summary and total paid.
- Responsive layout for the required testing sizes:
  - Mobile: 390 x 844
  - Desktop: 1368 x 912

## File Map

- `index.html`: Main semantic structure for the website sections and forms.
- `css/styles.css`: Visual design, responsive layout, product grid, cart, checkout, and confirmation styling.
- `js/app.js`: Product data, page navigation, search filtering, cart logic, subtotal calculation, item removal, and checkout validation.
- `assets/`: Temporary product image placeholders. These can be replaced with final shirt photos later.

## Notes

This version is intended as the final Week 3 code snapshot. It is still using placeholder product images, but the website flow and core JavaScript interactions are complete enough to demonstrate the assignment purchase journey.
